# docs

Project documents. Read them in this order when you are new to the project.

| File | Read it for |
| --- | --- |
| `PLAN.md` | Goal, phases, the gate to pass before each phase, current status and open decisions |
| `RUNNING.md` | Step by step commands to run the backend, the game and the Kaggle notebooks |
| `GAME_DESIGN.md` | The game loop, screens, tiers, word bank and the Godot state machine |
| `DATASETS.md` | Which datasets we use and why, licenses, and the protocol for recording our own data |
| `NOTEBOOKS.md` | What each Kaggle notebook does and what it must write to `results/` |
| `CLAUDE_CODE_PROMPT.md` | Prompts used to work with Claude Code in this repository |

## Keeping the docs true

1. Facts and numbers must trace to a source or to a file in `results/`. Do not copy numbers into the docs.
2. When behavior or the protocol changes, update the affected document in the same change.
3. Mark anything that is a plan or a placeholder as such.
